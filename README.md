Консоль управления сервером Minecraft должна:

1) уметь запускать и останавливать сервер;
2) постоянно показывать вывод сервера;
3) добавлять и удалять игроков из белого списка;
4) уметь менять режим игры каждого игрока;
5) уметь отправлять сообщения игроку;
6) уметь показывать все что пишется и отправляется в консоль сервером или игроками;
7) возможность взаимодействовать с миром (менять мир, генерацию мира);


Основные элементы консоли - файлы проекта:

1) страница index.html - сама страница веб-приложения
2) файл css/style.css - файл стилей CSS
3) src/frontend.js - отвечает за работу c DOM-деревом страницы
4) src/backend.js - отвечает за взаимодействие с сервером Minecraft
